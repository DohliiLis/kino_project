# Анализ функций приложения для планирования просмотра фильмов и сериалов

## Цель

Определить, какие функции стоит реализовать в приложении для сохранения планов на просмотр фильмов и сериалов и учёта просмотренного. Для этого сравниваются существующие сервисы и анализируются ответы в учебном моделировании опроса.

## Файлы проекта

- `competitor_data.csv` — сведения о 12 сервисах-конкурентах и наличии у них 7 функций.
- `survey_data.csv` — 200 синтетических анкет с ответами на 10 вопросов о желаемых функциях.
- `analisys.py` — скрипт анализа на Python с использованием Pandas и NumPy.

В таблицах `1` означает наличие функции или ответ «Да», `0` — отсутствие функции или ответ «Нет». Первый столбец содержит название сервиса либо условное имя участника и в подсчётах не используется.

Для запуска необходимо установить библиотеки (`pip install pandas numpy`) и выполнить `python analisys.py` из папки с CSV-файлами. Скрипт считает количество единиц, вычисляет процент от общего числа строк и выводит функции по убыванию процента.

## Выводы и приоритеты разработки

### Обязательно реализовать в первой версии

1. **Список просмотра** — сохранение фильмов и сериалов, которые планируется посмотреть (93% положительных ответов; присутствует у 12 из 12 конкурентов).
2. **Учёт просмотренного** — возможность отмечать завершённые просмотры (91%; 12 из 12 конкурентов).
3. **Оценки** — выставление собственной оценки фильму или сериалу (84,5%; 11 из 12 конкурентов).
4. **Прогресс просмотра серий** — отслеживание просмотренных эпизодов (72%; 10 из 12 конкурентов).
5. **Рекомендации** — предложения фильмов и сериалов для просмотра (68,5% в моделировании опроса). Эта функция не сравнивалась в таблице конкурентов; способ формирования рекомендаций предстоит определить отдельно.

### Рассмотреть для следующих версий

1. **Отзывы и заметки** — 55% положительных ответов; функция присутствует у 10 из 12 аналогов. Несмотря на распространённость у конкурентов, в моделировании она оказалась менее приоритетной, чем пять функций выше.
2. **Совместные списки** — 37% положительных ответов; функция присутствует у 4 из 12 аналогов. Может быть полезна для совместного планирования просмотров.
3. **Случайный выбор** — 34% положительных ответов; функция присутствует у 3 из 12 аналогов. Может помочь выбрать фильм из уже сохранённого списка.

### Низкий приоритет

- **Сохранение ссылок на просмотр** — 17,5% положительных ответов.
- **Ручное добавление фильмов** — 9% положительных ответов.

Эти две функции целесообразно отложить до появления более важных возможностей. В таблице конкурентов они отдельно не исследовались.

## Итог

На основании сравнения аналогов и результатов учебного моделирования предложено включить в первую версию приложения **пять основных функций**, **три функции оставить для возможных обновлений**, а **две — отнести к низкому приоритету**.

Такое распределение служит предварительным планом разработки. Для подтверждения реального интереса пользователей потребуется провести настоящий опрос, а для окончательного выбора функций — учесть сложность реализации и сроки проекта.
